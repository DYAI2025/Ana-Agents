# Troubleshooting

## Skill does not appear/install

- Verify you are using an approved ZIP from the exact repository release/candidate.
- Verify the archive contains top-level `SKILL.md` and `agents/openai.yaml`.
- Do not assume a ChatGPT plan/workspace supports the same installation UI; record the exact UI blocker.

## Brand Intel claims it validated schemas but no validator ran

Treat that claim as invalid. Schema/chain PASS requires actual validator execution.

## Composer starts browsing the Brand

Stop. The composer is out of scope. Missing Brand evidence must go back to Brand Intel.

## Agent wants to send because a draft exists

Stop. Draft readiness is not send authorization.

## CRM write is unavailable

Do not broaden permissions automatically. Record `CAPABILITY_MISSING` or the missing authorization.

## Contact exists but is not eligible

Keep contact readiness separate from fit. REVIEW_REQUIRED and NO_SEND are valid.

## Production orchestrator integration cannot be verified

Current expected state until the authoritative Vince orchestrator artifact is identified: `MISSING`.
